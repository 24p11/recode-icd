## Consignes nouvelles

### GM2026-V-POL-01 — `regle_association`

**Situation** : Polyhandicap lourd — un code de chacune des quatre listes

**Texte** : Le polyhandicap se définit par l'association de quatre critères : déficience mentale profonde ou démence sévère ; trouble moteur (paralysie partielle ou totale, ataxie, tremblements sévères, dyskinésie, dystonie) ; mobilité réduite conséquence du trouble moteur ; restriction extrême de l'autonomie (dépendance permanente envers une tierce personne ou un appareil). Quatre listes de codes CIM-10 (élaborées sous le contrôle de la SFP et de la SFNP, publiées sur le site de l'ATIH) portent ces critères : un code au moins de chacune des quatre listes doit être présent dans le RSS pour affirmer le polyhandicap lourd.

**Condition** : —

**Citation** (`polyhandicap_lourd.md` L10-24) :
« Le polyhandicap se définit par l’association de quatre critères : […] Pour permettre l’identification du polyhandicap lourd dans les recueils d’informations du PMSI, quatre listes de codes de la CIM–10 ont été élaborées sous le contrôle de la Société française de pédiatrie et de la Société française de neuropédiatrie […] Un code au moins de chacune des quatre listes […] doit être présent dans le RSS pour affirmer le polyhandicap lourd. »

*Aucune association.* Le guide ne nomme ici aucun code : en attribuer supposerait de **choisir** des cibles que le texte ne donne pas.
